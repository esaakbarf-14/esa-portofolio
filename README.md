# ESA — Developer Portfolio

A modern, interactive personal developer portfolio built with **React.js**, **Tailwind CSS**, and **Framer Motion**.

This portfolio is designed to showcase my background, education, professional experience, technical skills, projects, certifications, language skills, and contact information through a modern **dark-themed developer interface**.

The website combines a clean futuristic UI with subtle animations, smooth scrolling, responsive layouts, and interactive elements to create a professional and engaging browsing experience.

---

## 🚀 Overview

This project represents my personal portfolio as a **Web Developer / Software Developer**.

The portfolio focuses on presenting both my technical capabilities and professional journey in a visual and interactive way.

Instead of using a traditional static portfolio layout, the interface is designed around a modern developer-oriented aesthetic with:

* Dark futuristic interface
* Blue and white visual identity
* Smooth section transitions
* Interactive navigation
* Scroll progress indicator
* Responsive design
* Animated UI components
* Developer-inspired terminal section
* Project showcase

* Skills and technology showcase
* Certificates section
* Language section
* Contact section

## 🔧 Installation

Clone this repository:

```bash
git clone https://github.com/yourusername/developer-portfolio.git
```

Navigate to the project directory:

```bash
cd developer-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the local development server in your browser:

```text
http://localhost:5173
```

---

## 🏗️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
